Trainmaster Command Control

It has one advantage over DCC, in that TMCC-equipped locomotives can run simultaneously with non-TMCC locomotives and Lionel Legacy engines as well as LionChief and LionChief Plus equipped locomotives.

The latter require a dedicated remote controller.

MTH Corporation's DCS controller can be configured to control TMCC locomotives, and all four systems (TMCC, Legacy, LionChief/LionChief+ and DCS) can be operated on the same track simultaneously.
