Manson-Guise Engine

Providing there is a large enough temperature difference between the two sides the engine will run.

The Manson-Guise engine is probably the simplest type of hot air engines having only a single con-rod, with a displacer piston and power piston that move at the same time.

Manson-Guise engines seem to be fairly unique in the fact that they can run in either direction (flywheel can run clockwise or anti-clockwise).
