NTFS symbolic link

Symbolic links should be transparent to users; the links appear as normal files or directories, and can be acted upon by the user or application in exactly the same manner.

Symbolic links to directories or volumes, called junction points and mount points, were introduced with NTFS 3.0 that shipped with Windows 2000.

From NTFS 3.1 onwards, symbolic links can be created for any kind of file system object.
