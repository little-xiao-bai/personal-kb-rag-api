Atari XEGS

Additionally, it is able to operate as either a stand-alone console or full computer with the addition of its specially designed keyboard.

In computer mode, it may utilize the majority of peripherals released for Atari's 8-bit computer line.

Atari packaged the XEGS as a basic set consisting of only the console and joystick, and as a deluxe set consisting of the console, keyboard, joystick and light gun.
